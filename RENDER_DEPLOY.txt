# Render deploy checklist (Luma)
# Goal: API web service + frontend static site

================================================================================
A. BEFORE RENDER (Atlas)
================================================================================
1. Atlas → Network Access → Add IP → Allow Access from Anywhere (0.0.0.0/0)
2. Keep your MONGO_URI ready (already in backend/.env locally)

================================================================================
B. PUSH CODE TO GITHUB
================================================================================
1. Create a GitHub repo
2. Push this project (do NOT commit backend/.env or frontend/.env)
3. Connect that repo in Render

================================================================================
C. BACKEND (Render → New → Web Service)
================================================================================
- Root Directory: backend
- Runtime: Node
- Build Command: npm install && npm run build
- Start Command: npm start
- Instance: Free
- Health Check Path: /health

Environment variables:
  NODE_ENV=production
  PORT=10000
  USE_MEMORY_DB=false
  MONGO_URI=<your atlas uri with /luma?... >
  JWT_SECRET=<long random string>
  JWT_EXPIRES_IN=7d
  FRONTEND_ORIGIN=https://<your-frontend>.onrender.com
  CLOUDINARY_CLOUD_NAME=...
  CLOUDINARY_API_KEY=...
  CLOUDINARY_API_SECRET=...

After deploy, copy the API URL, e.g.:
  https://luma-api-xxxx.onrender.com

Test: https://luma-api-xxxx.onrender.com/health

================================================================================
D. FRONTEND (Render → New → Static Site)
================================================================================
- Root Directory: frontend
- Build Command: npm install && npm run build
- Publish Directory: dist

Environment variables (set BEFORE build):
  VITE_API_URL=https://luma-api-xxxx.onrender.com/api
  VITE_SOCKET_URL=https://luma-api-xxxx.onrender.com

Rewrite rule (SPA):
  Source: /*
  Destination: /index.html

================================================================================
E. FINAL HOOKUP
================================================================================
1. Set backend FRONTEND_ORIGIN to the exact frontend URL (https, no trailing slash)
2. Redeploy backend if you changed FRONTEND_ORIGIN
3. Redeploy frontend if API URL changed
4. Open frontend → register 2 users → test chat + image

================================================================================
NOTES
================================================================================
- Free Render services sleep after idle (~15 min); first request can be slow
- Auth uses Bearer token in localStorage (works cross-origin)
- Socket.IO needs the same VITE_SOCKET_URL host as the API
- Never commit secrets; rotate Atlas password after sharing in chat
